# Site da Associação Flor da Mangaba (AFM)

Site publicado em https://flordamangaba.github.io pelo GitHub Pages.

- index.html – todo o conteúdo (textos, notícias, diretoria, contato)
- estilo.css – visual; as cores ficam no topo do arquivo
- favicon.svg – ícone da flor

Domínio próprio: crie o arquivo CNAME com o domínio (ex.: flordamangaba.org.br) e aponte o DNS para o GitHub Pages.
